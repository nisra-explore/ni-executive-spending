#36 ELMS public spending dashboard - data processing

## :newspaper: Aim
Documentation to outline the structure and processes needed to prepare the data for the ELMS public spending dashboard.  Linked to [dashboard code repository](https://github.com/NISRA-Tech-Lab/36-prototye-dashboard) 

## :house: Structure

### File structure 

| File | Purpose  |
| --- | --- |
| `data_processing.R` | The data processing main file |
| `dashboard_tables.R` | R code to prepare the data for publication alongside the dashboard |
| `new_worksheet.R` | Functions needed by the dashboard_tables.R |
| `styles.R` | Styles needed for the excel file formatting |
| `\data folder` | Folder to hold the two main input files (labels and PSD data) - these are not pushed to git |


## :bell: Processes

Please refer to the main dashboard repository readme for instructions on data processing and data download preparation
